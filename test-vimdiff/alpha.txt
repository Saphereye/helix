## Chapter 2: Architecture

The editor core lives in helix-core. Document state is managed by helix-view.
The terminal UI is helix-term. Tree-sitter provides syntax highlighting.

Buffer diff links documents through diff_group and diff_compare fields.
Inline highlights use word-level Myers diff on changed lines only.
